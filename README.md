# 🎯 Trading Dashboard | داش بورد توصيات التداول

نظام متكامل لتوليد وعرض توصيات التداول بناءً على استراتيجيات مُختبرة.

## 📦 المتطلبات

```bash
pip install streamlit pandas numpy alpaca-py ta
```

## 🚀 التشغيل

```bash
cd trading_dashboard
python run.py
```

ثم افتح المتصفح على: `http://localhost:8501`

## 📊 المميزات

### 1️⃣ التوصيات التلقائية
- مسح 15+ سهم على 3 إطارات زمنية
